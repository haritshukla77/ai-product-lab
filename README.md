# Harit Shukla · AI Product Lab

I build AI product case studies to test how agents fit into real workflows. The projects show how I define scope, choose where to automate, and decide what evidence is needed before expanding a rollout.

## Featured Projects

### 1. Transcript to Linear

**Turn meeting decisions into an approved engineering backlog.** Mistral extracts a transcript, drafts a PRD, and prepares Linear issues. A reviewer approves scope and then confirms the issue changes. Saved requirement IDs let later feedback update the original issue. One live rehearsal created 12 issues, updated one in place, and made zero writes on replay. [Case study](Transcript-to-Linear/README.md) · [Runbook](Transcript-to-Linear/RUNBOOK.md) · [Evals](Transcript-to-Linear/evals/README.md)

### 2. AI News Agent using IBM BOB

**Deliver a curated daily AI digest with a predictable local pipeline.** I used IBM BOB to plan and build a Python workflow for scheduled retrieval, keyword scoring, formatting, and Gmail delivery. Keyword rules make curation easy to inspect. The deployment guide and diagnostics show how to investigate source and delivery failures. [Case study](AI-News-Agent/README.md) · [Architecture](AI-News-Agent/Documentation/PLAN.md) · [Run locally](AI-News-Agent/Code/README.md)

### 3. Agentic Workflow Automation using UiPath Maestro

**Put a human approval gate before an agent-generated newsletter is sent.** I implemented the DevPulse tutorial in Maestro Automate and configured Gmail delivery. The demo documents the workflow canvas, inline review, an approved email, and recovery from environment and connector issues. [Case study](Maestro_Automate_Solution_HS/Readme.md) · [Workflow export](Maestro_Automate_Solution_HS/Flow/new.bpmn)

### 4. Strategic Decision OS

**Help product and platform leaders evaluate build, partner, or hybrid choices.** The Gemini-based prototype runs product, platform, finance, and risk reviews in sequence. It pauses for judgment when evidence is weak or risks need review, then produces a decision memo. The built-in case concerns agent orchestration for a regulated healthcare platform. [Case study](Decision%20OS%20Agent/README.md) · [PRD](Decision%20OS%20Agent/docs/PRD.md) · [Implementation](Decision%20OS%20Agent/src/)
